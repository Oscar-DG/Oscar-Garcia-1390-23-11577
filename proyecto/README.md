# Proyecto Desarrollo Web

Este es el proyecto realizado para el primer parcial de Desarrollo Web.

Se trabajo con HTML y CSS para hacer las paginas y con Flask para poder navegar entre ellas.

El proyecto tiene una pagina de inicio y 4 paginas mas donde se utilizaron tablas, formularios, listas, imagenes y etiquetas semanticas.

Tambien se utilizo Flask para las rutas, formularios con GET y POST y variables con Jinja2.

## Para ejecutar

Abrir la terminal en la carpeta del proyecto y ejecutar:

python app.py

Luego abrir la direccion que muestra Flask en el navegador.

## Debug

Se utilizo debug=True para poder hacer las pruebas durante el desarrollo y ver los errores mas facilmente.

debug=True se utiliza solamente durante el desarrollo y no se debe utilizar cuando la aplicacion esta en produccion.
